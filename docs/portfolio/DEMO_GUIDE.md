# BIDEO 3분 40초 시연 영상

프로젝트의 주요 서비스 화면을 기록한 실제 시연 영상입니다.

[실제 BIDEO 시연 영상 보기](demo/bideo-demo.mp4)

## 권장 녹화 구성

| 시간 | 화면 | 설명할 핵심 |
|---|---|---|
| 0:00–0:30 | 메인·프로젝트 소개 | 디지털 작품의 전시부터 거래까지 연결한 플랫폼 |
| 0:30–1:30 | 작품 등록 | 파일·태그·예술관 관계 저장, S3 object key와 presigned URL |
| 1:30–2:10 | 예술관 상세 | 작품 연결, 수정·삭제 시 연관 데이터 정리 |
| 2:10–3:10 | 경매 입찰 | 유효성 검증, `SELECT FOR UPDATE`, 최고 입찰 유일 인덱스 |
| 3:10–4:00 | Bootpay 결제 | 서버 영수증·금액·주문번호 검증과 영수증 재사용 차단 |
| 4:00–4:40 | AI 기능 | 조회수 예측, 인기 분류, 유사도 추천, 경매 RAG |
| 4:40–5:00 | CI·마무리 | Java·FastAPI 테스트와 GitHub Actions 성공 화면 |

## 녹화 전 체크리스트

- 테스트용 계정과 작품·예술관 데이터를 준비합니다.
- 문자·메일 인증이 비활성화된 데모라면 화면 시작 전에 이를 한 문장으로 고지합니다.
- 실제 결제를 수행하지 않는 경우 Bootpay 테스트 모드임을 표시합니다.
- 개인정보, API 키, 결제 영수증 원문, AWS 콘솔의 민감값은 녹화하지 않습니다.
- README의 ERD와 플로우차트는 코드 화면 사이를 설명할 때만 짧게 사용합니다.

## 면접 설명 문장

> 작품과 예술관 CRUD를 중심으로 S3 파일 저장, 경매 동시성, 결제 서버 검증, FastAPI AI 기능을 직접 연결했습니다. 경매는 DB 행 잠금과 유일 인덱스로 경쟁 상태를 방지하고, 결제는 동일 Bootpay 영수증의 재사용을 애플리케이션과 DB에서 이중 차단했습니다.
