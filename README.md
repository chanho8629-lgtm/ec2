# 🚀 BIDEO - 데이터 기반 영상 경매 플랫폼

## 공공 데이터 분석: 기획 배경

BIDEO는 영상 콘텐츠를 단순히 업로드하고 조회수로 평가하는 플랫폼이 아니라, 시장 수요에 따라 가격이 형성되는 **영상 경매 플랫폼**이다.

본 분석은 실제 공개 통계와 보도자료 기반 데이터를 사용해 다음 흐름으로 진행했다.

1. 국내 콘텐츠산업 시장 성장 확인
2. OTT 이용률 증가를 통한 영상 콘텐츠 수요 확인
3. 1인 미디어 창작자 수익 집중도 확인
4. BIDEO 서비스 기획 근거 도출

## 1. 분석 목적

- 국내 콘텐츠산업 매출이 지속적으로 성장하고 있는지 확인한다.
- OTT 이용률 증가로 영상 콘텐츠 소비 기반이 확대되고 있는지 확인한다.
- 1인 미디어 창작자 수익이 일부 상위 창작자에게 집중되는지 확인한다.
- 조회수 중심 평가를 넘어 **참여도와 입찰 경쟁 기반 가치 평가**가 필요한 이유를 도출한다.

## 2. 사용 데이터

| 데이터 | 기간 | 주요 지표 | 출처 |
| --- | --- | --- | --- |
| 콘텐츠산업 매출액 | 2020~2024 | 콘텐츠산업 전체 매출액(조 원) | 문화체육관광부·한국콘텐츠진흥원 콘텐츠산업조사 |
| OTT 이용률 | 2021~2024 | OTT 이용률, 유료 OTT 이용 비율 | 방송통신위원회 방송매체 이용행태조사 |
| 1인 미디어 창작자 수입 | 2023 | 상위 1%, 상위 10%, 하위 50% 수입 | 국세청 자료 기반 언론 보도 |

## 4. 콘텐츠산업 시장 성장 분석

국내 콘텐츠산업 전체 매출액이 증가하는지 확인했다. 시장 규모가 커지고 있다면 영상 콘텐츠 거래 플랫폼의 진입 기반도 함께 확대된다고 볼 수 있다.

<p align="center">
  <img src="images/bideo_market_growth.png" width="720" alt="국내 콘텐츠산업 매출액 추이">
</p>

### 해석

국내 콘텐츠산업 매출액은 2020년 **128.3조 원**에서 2024년 **157.4조 원**으로 증가했다. 이는 콘텐츠 시장이 단기 유행이 아니라 지속적인 산업 규모를 형성하고 있음을 보여준다.

BIDEO 입장에서는 완성된 영상 콘텐츠를 거래 가능한 자산으로 다루는 서비스 모델의 시장 기반이 존재한다고 해석할 수 있다.

## 5. OTT 이용률 증가 분석

영상 콘텐츠 소비 기반이 확대되고 있는지 확인하기 위해 OTT 이용률과 유료 OTT 이용 비율을 함께 시각화했다.

<p align="center">
  <img src="images/bideo_usage_rate.png" width="720" alt="국내 OTT 이용률 증가 추이">
</p>

### 해석

OTT 이용률은 2021년 **69.5%**에서 2024년 **79.2%**로 상승했다. 유료 OTT 이용 비율도 2022년 **55.9%**에서 2024년 **59.9%**로 증가했다.

이는 사용자가 영상 콘텐츠를 소비하는 데 그치지 않고 비용을 지불하는 경험에도 익숙해지고 있음을 의미한다. 따라서 영상 콘텐츠를 거래 대상으로 삼는 BIDEO의 서비스 기획과 연결된다.

## 6. 1인 미디어 창작자 수익 집중도 분석

콘텐츠 시장과 이용자는 증가하지만, 창작자 수익이 고르게 분배되는지는 별도의 문제다. 국세청 자료 기반 보도 수치를 활용해 2023년 1인 미디어 창작자 수입 집중도를 확인했다.

| 2023년 창작자 수입 집중도 | 2023년 창작자 평균 수입 격차 |
| --- | --- |
| <img src="images/bideo_creator_income.png" width="430" alt="2023년 1인 미디어 창작자 수입 집중도"> | <img src="images/bideo_growth_gap.png" width="430" alt="2023년 창작자 평균 수입 격차"> |

### 해석

2023년 1인 미디어 창작자 수입은 상위 10%가 전체의 약 **50.3%**를 차지했다. 상위 1%의 평균 수입은 약 **13.25억 원** 수준으로 나타난 반면, 하위 50% 평균 수입은 약 **1,800만 원** 수준으로 보도되어 수익 격차가 크다.

이는 기존 플랫폼 구조에서 콘텐츠 시장 성장의 이익이 모든 창작자에게 고르게 돌아가지 않을 수 있음을 보여준다.

## 7. BIDEO 서비스 지표 설계

기존 플랫폼의 조회수 중심 평가는 콘텐츠의 노출 규모를 보여주는 데 강점이 있지만, 실제 구매 의사와 가격 형성력을 설명하기에는 한계가 있다.

BIDEO는 다음과 같은 참여도·경쟁 기반 지표를 서비스 가치 평가에 활용할 수 있다.

| 지표 | 계산식 | 의미 |
| --- | --- | --- |
| 좋아요 비율 | `likes / views` | 조회수 대비 긍정 반응 |
| 댓글 비율 | `comments / views` | 조회수 대비 적극 의견 반응 |
| 공유 비율 | `shares / views` | 콘텐츠 확산 가능성 |
| 참여도 점수 | `likes + comments + shares` | 콘텐츠 반응 총량 |
| 입찰자 수 | `bidder_count` | 구매 의사가 있는 수요자 규모 |
| 로그 조회수 | `log(views + 1)` | 조회수 편차 완화 |
| 로그 낙찰가 | `log(final_bid_price + 1)` | 가격 편차 완화 |

## 8. 최종 결론

### 시장성

콘텐츠산업 매출과 OTT 이용률이 함께 증가하고 있어 영상 콘텐츠를 거래 대상으로 삼는 플랫폼의 시장 진입 근거가 있다.

### 문제점

기존 플랫폼은 조회수, 광고 수익, 구독자 규모에 의존하는 경향이 크다. 시장은 성장하지만 창작자 수익은 상위 창작자에게 집중되어 신규·중소 창작자의 수익화 기회가 제한될 수 있다.

### 서비스 기획 연결

BIDEO는 영상 콘텐츠에 입찰 경쟁을 도입해 콘텐츠의 수요를 가격으로 드러낸다. 플랫폼의 핵심 가치는 `조회수 기반 평가`가 아니라 `참여도와 구매 경쟁 기반 가치 평가`에 있다.

> **사람들이 얼마나 보고 지나갔는지가 아니라, 얼마나 반응하고 경쟁했는지가 콘텐츠의 가격을 만든다.**
